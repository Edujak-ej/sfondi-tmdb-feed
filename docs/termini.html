Che cosa fa l'app

L'app pubblica automaticamente, tre volte al giorno, un'immagine di sfondo nel subreddit r/tmdbwallpapersita. Ogni immagine è composta a monte da un processo automatico a partire dai dati di The Movie Database, e mostra titolo, generi, durata o numero di stagioni, interpreti principali, regia, trama e valutazioni. Lo scopo è avere una raccolta di sfondi in italiano da usare come sorgente per i launcher delle smart TV.

Contenuti e diritti di terzi

Questo progetto utilizza le API di TMDB ma non è approvato né certificato da TMDB. Le valutazioni provengono dalle API di OMDb. Ogni immagine riporta l'attribuzione a TMDB. What the app does

Three times a day the app automatically posts one wallpaper image to the subreddit r/tmdbwallpapersita. Each image is composed beforehand by an automated process from The Movie Database data and shows title, genres, runtime or number of seasons, main cast, director, synopsis and ratings. The purpose is a collection of Italian-language wallpapers to be used as a source by smart TV launchers.
